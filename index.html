Welcome to TimeBuddy!

TimeBuddy is a student-friendly web application that helps students organize their daily activities. It brings reminders, notes, and important documents together in one place.

About TimeBuddy

Students often need to manage lectures, assignments, study time, and important documents. TimeBuddy is designed to make these tasks easier and more organized.

Main Features

1. Daily Reminders

Set reminders for study sessions and daily tasks.

2. Voice Reminders

Hear spoken reminders when the feature is enabled and the webpage is running.

3. Notes

Save useful study notes for future reference.

4. Important Documents

Keep selected study documents accessible through the application.

5. Time Management

Plan daily activities and build better study habits.

How to Use TimeBuddy

  1. Open the TimeBuddy application.
  2. Add a reminder and select its time.
  3. Enable voice reminders if you want spoken alerts.
  4. Write and save your notes.
  5. Add important documents when needed.

Benefits for Students

  • Helps organize daily tasks.
  • Makes study planning easier.
  • Keeps notes and documents accessible.
  • Encourages better time management.

Technologies Used

HTML: Creates the structure of the webpage.

CSS: Adds colors, spacing, and design.

JavaScript: Adds interactive features.

Conclusion

TimeBuddy aims to make student life more organized by bringing everyday study tools together. It is a simple project designed around students' needs.
